Privacy Policy

Application: Endless Arcade • Package ID: com.aashiqhasnat.endlessarcade • Last Updated: September 7, 2026

This Privacy Policy applies to the Endless Arcade mobile application.

1. Information Collection and Use

The application does not collect, transmit, store, or sell any personal identifying information (such as names, email addresses, phone numbers, contacts, or device location).

Data Type Collected Storage Purpose
Personal Information No None Not required
Device Location No None Not required
Game Progress (Coins, Unlocks, Scores) Yes Local Device Storage Saves game progress locally on your device
Settings (Audio, Controls) Yes Local Device Storage Retains user preferences locally

2. Device Permissions

The application uses the following device permissions:

  • Vibration (android.permission.VIBRATE): Provides haptic feedback during gameplay.
  • Network Access (ACCESS_NETWORK_STATE / INTERNET): Used for optional local Wi-Fi multiplayer and Google Play platform services.

3. Data Storage and Security

All gameplay records, unlocked items, and user settings are stored locally on your device's internal storage. No gameplay data is sent to external developer servers.

4. Third-Party Services

The application does not integrate third-party advertising SDKs or analytics tracking frameworks. If optional Google Play Services are used, data is processed in accordance with the Google Privacy Policy.

5. Children's Privacy

The application is suitable for all ages and does not knowingly collect personal information from children under 13 years of age.

6. Data Deletion

Users can delete all locally stored game data at any time by clearing application data in the Android device settings, uninstalling the application, or using the in-game reset option in Settings.
